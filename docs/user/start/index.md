# Get started

Wingman runs on the PC that runs Ultrastar Deluxe. Everybody else opens it in a
browser, and there is nothing to install on a phone.

Getting a party going takes three steps, in this order. Start Wingman on the
karaoke PC. Point it at Ultrastar Deluxe and at your songs. Then let the guests
scan the QR code on the TV.

## What you need

- Ultrastar Deluxe, installed and started at least once.
- A folder with songs in it. Ultrastar Deluxe's own songs folder is the usual
  one, and any other folder works too.
- `UltrastarWingman.exe`, or the Wingman source folder if you would rather run
  it from there.
- The karaoke PC and every guest phone on the same network.

## The pages in this section

- [Install and run](install.md): start Wingman, find the data folder, and

- [Connect Ultrastar Deluxe](ultrastar-deluxe.md): the two settings that let a

Once the first song can start, the rest of the site is about the evening
